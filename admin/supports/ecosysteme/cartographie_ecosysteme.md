# CARTOGRAPHIE DE MON ÉCOSYSTÈME ORGANISATIONNEL

## GUIDE DE RÉALISATION

Cette cartographie vous aide à visualiser et analyser votre système actuel d'organisation personnelle.

### Instructions
1. Identifiez tous les outils et méthodes que vous utilisez actuellement
2. Placez-les sur la grille selon leur fonction principale
3. Connectez les éléments qui interagissent entre eux
4. Identifiez les points forts et les lacunes de votre écosystème

## FONCTIONS CLÉS D'UN ÉCOSYSTÈME ÉQUILIBRÉ

### 1. CAPTURE
*Où et comment collectez-vous les nouvelles informations?*

**Rôle**: Recueillir sans friction toutes les informations entrantes (idées, tâches, contacts, références)

**Exemples d'outils**:
- Inbox email/messagerie
- Carnet ou bloc-notes de capture
- Application de notes rapides
- Enregistrements vocaux
- Boîte de réception physique
