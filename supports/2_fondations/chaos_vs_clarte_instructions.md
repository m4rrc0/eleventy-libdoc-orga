# Exercice "Chaos vs Clarté"
## Instructions de préparation

### Objectif de l'exercice
Faire expérimenter concrètement aux participants l'impact des structures organisationnelles sur leur capacité à traiter l'information.

### Matériel à préparer (par participant)

#### 1. Enveloppe "Chaos"
Pour chaque participant, préparer une enveloppe contenant 10-15 petits papiers (type post-it coupés en deux ou fiches bristol 5×7cm). Sur chaque papier, noter une information appartenant aux catégories suivantes:

**Tâches** (3-4 exemples)
- "Appeler le client au 06 XX XX XX XX avant jeudi"
- "Finaliser la présentation pour la réunion du 15 juin"
- "Acheter du lait en rentrant ce soir"
- "Répondre au mail de l'équipe projet"

**Rendez-vous** (2-3 exemples)
- "Réunion d'équipe - Mardi 10h - Salle Bleue"
- "Dentiste - Jeudi 15h30 - Dr. Martin"
- "Appel client - Mercredi 14h - Zoom ID: 123-456-789"

**Idées à explorer** (2-3 exemples)
- "Essayer la méthode Pomodoro pour améliorer ma concentration"
- "Réorganiser mon classement de fichiers par projets plutôt que par dates"
- "Proposer un nouveau format pour les réunions hebdomadaires"

**Contacts/Informations** (2-3 exemples)
- "Pierre Dupont - expert en design thinking - pierre@exemple.com"
- "Code wifi bureau: Orga2025!"
- "Numéro de dossier projet Horizon: PRJ-2025-06-123"

**Tâches récurrentes** (1-2 exemples)
- "Sauvegarder les fichiers de travail chaque vendredi"
- "Planifier la semaine le dimanche soir"

#### 2. Feuille de structure "Clarté"
Préparer une feuille A4 par participant avec la structure suivante:

```
┌──────────────────────────────────┐
│ URGENCES (à faire aujourd'hui)   │
│                                  │
│                                  │
│                                  │
├──────────────────────────────────┤
│ IMPORTANT (à planifier)          │
│                                  │
│                                  │
│                                  │
├──────────────────────────────────┤
│ À RÉFÉRENCER (à conserver)       │
│                                  │
│                                  │
│                                  │
├──────────────────────────────────┤
│ À DÉLÉGUER                       │
│                                  │
│                                  │
├──────────────────────────────────┤
│ À ÉLIMINER                       │
│                                  │
│                                  │
└──────────────────────────────────┘
```

#### 3. Fiche d'instructions
Préparer une fiche avec les instructions suivantes:

**Phase 1: Chaos**
- Vous avez 2 minutes pour mémoriser toutes ces informations
- Essayez de retenir le maximum de détails (dates, noms, numéros...)
- Après 2 minutes, notez tout ce dont vous vous souvenez

**Phase 2: Clarté**
- Utilisez la structure fournie pour organiser ces mêmes informations
- Placez chaque élément dans la catégorie qui vous semble appropriée
- Après avoir organisé, prenez 2 minutes pour mémoriser à nouveau
- Notez ce que vous avez retenu cette fois-ci

### Instructions pour l'animation

#### Préparation
1. Distribuer uniquement les enveloppes "Chaos" au début
2. Prévoir un chronomètre visible de tous
3. Préparer un tableau pour noter les observations des participants

#### Déroulement
1. **Introduction** (1 min)
   - Expliquer qu'il s'agit d'une expérience comparative
   - Ne pas dévoiler l'objectif complet pour ne pas biaiser l'exercice

2. **Phase Chaos** (3 min)
   - Annoncer clairement le début du chronomètre: "Vous avez 2 minutes à partir de maintenant"
   - Après 2 minutes: "Stop! Rangez vos papiers"
   - Demander de noter ce qu'ils ont retenu (1 min)

3. **Phase Clarté** (4 min)
   - Distribuer la feuille de structure
   - Donner 3 minutes pour organiser et mémoriser
   - Après 3 minutes: "Stop! Notez ce que vous avez retenu"

4. **Débrief immédiat** (2 min)
   - Demander: "Quelle approche a facilité la rétention d'information?"
   - "Qu'avez-vous ressenti pendant la première phase? Et pendant la seconde?"
   - "Quelle différence remarquez-vous entre vos deux listes de souvenirs?"

#### Points d'observation pour le formateur
- Noter les réactions non-verbales de stress/confusion pendant la phase Chaos
- Observer les stratégies spontanées d'organisation (certains essaieront de catégoriser même sans structure)
- Repérer les participants qui semblent déjà avoir des systèmes d'organisation efficaces

### Variantes possibles
- **Version courte**: Réduire à 5-7 éléments d'information par enveloppe
- **Version avancée**: Ajouter des éléments de distraction pendant la phase Chaos
- **En binôme**: Faire l'exercice en équipes de deux si manque de matériel
